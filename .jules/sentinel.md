## YYYY-MM-DD - [Prevent arbitrary code execution in sandbox expression evaluation]
**Vulnerability:** [The AXIOM expression sandbox in scripts/sandbox.py used Python's `eval()` to execute user-provided expressions, allowing arbitrary code execution (e.g. `__import__('os').listdir('.')`).]
**Learning:** [Using `eval()` on unsanitized strings is inherently unsafe, even in a subprocess, without strict OS-level containerization (which wasn't present or active in the Python code itself). Additionally, limiting AST traversal to just `BinOp` and `UnaryOp` can break math functions, and simply mapping `ast.Mult` to `operator.mul` can still allow resource exhaustion via sequence repetition like `[0]*10**9`.]
**Prevention:** [Replace `eval()` with a custom `ast.NodeVisitor` that strictly whitelists permitted AST nodes (like basic math operators, whitelisted `math` module attributes/functions, and safe builtins) and actively checks types for multiplication to prevent sequence repetition resource exhaustion.]
