## 2025-05-10 - Sandbox RCE via eval()
**Vulnerability:** `scripts/sandbox.py` executed arbitrary mathematical expressions from untrusted users using the dangerous `eval()` method within a child process wrapper. The isolation mechanism (timeout/subprocess) failed to prevent execution of built-in system modules like `os`.
**Learning:** Process isolation or timeouts alone are insufficient protections when passing untrusted user input directly to interpreters. Even with wrappers that avoid immediate shell injection, `eval()` permits total code execution. The vulnerability is often subtle because `eval()` is assumed to be constrained to basic math, but it allows any valid Python expression, including dynamic imports.
**Prevention:** Use an Abstract Syntax Tree (AST) parser (e.g. `ast.parse`) with strict node allowlisting to strictly enforce and evaluate safe language constructs (such as constants and arithmetic operators), eliminating arbitrary function invocation or method execution.
