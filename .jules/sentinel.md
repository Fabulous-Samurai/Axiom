## 2024-10-27 - [Sandbox Python eval() Vulnerability]
**Vulnerability:** A critical security vulnerability was discovered in `scripts/sandbox.py` where `eval()` was used to evaluate arbitrary expressions passed to a subprocess.
**Learning:** Python's `eval()` function is unsafe for evaluating untrusted input, even when executed in a subprocess. Attackers can execute arbitrary code (e.g., file system access, command execution) or cause denial of service (e.g., infinite loops, memory exhaustion). `ast.literal_eval()` is also insufficient as it doesn't support basic binary operations (`2 + 2`).
**Prevention:** To securely evaluate mathematical expressions from untrusted strings, implement a custom `ast.NodeVisitor` to strictly parse and restrict allowed AST nodes. Disallow function calls (`visit_Call`), string multiplication (DoS via large strings), and large exponents. Additionally, ensure `generic_visit` is explicitly overridden to raise an exception for unhandled nodes, preventing attackers from smuggling malicious payloads via unexpected node types.
