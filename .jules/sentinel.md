## 2025-02-27 - [Fix Sandbox Escape Vulnerability in Python `eval()`]
**Vulnerability:** A critical Remote Code Execution (RCE) vulnerability in `scripts/sandbox.py` allowed an attacker to execute arbitrary code via the `run_isolated_expression` function, which passed unvalidated user input to Python's `eval()` function inside a subprocess.
**Learning:** `eval()` should never be used on untrusted input, even within a subprocess, as it executes arbitrary code. The use of `eval()` inherently undermines any language-level isolation. An attacker could trivially bypass the intended restrictions by passing expressions like `__import__('os').system('cat /etc/passwd')`.
**Prevention:** To avoid this in the future, implement a safe and strictly controlled Abstract Syntax Tree (AST) evaluator using `ast.NodeVisitor` or use Python's built-in `ast.literal_eval` for literals. Explicitly reject all `ast.Call` nodes and override `generic_visit` to throw exceptions on any unsupported syntax nodes.
