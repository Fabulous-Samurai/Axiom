## YYYY-MM-DD - [Sandbox Python eval() Vulnerability Fix]
**Vulnerability:** Arbitrary Code Execution (ACE) due to unsafe use of `eval()` in `scripts/sandbox.py`. Even though `sandbox.py` is intended to execute code safely, the implementation used `eval(expression)` allowing any valid Python expression. Builtins and module imports were not sufficiently restricted, allowing an attacker to run code like `__import__('os').listdir('.')` to break out of the sandbox.
**Learning:** Simply using `eval()` to evaluate expressions is unsafe because attackers can use it to import dangerous modules like `os` or `sys`. Trying to whitelist via `__builtins__` in `eval` is insufficient against MRO traversal attacks.
**Prevention:** To prevent arbitrary code execution, `ast.NodeVisitor` must be used to perform strict AST-based evaluation of user-provided expressions. This allows whitelisting specific mathematical operations, function calls, and constant variables while completely blocking imports and unauthorized methods.
