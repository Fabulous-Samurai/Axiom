## 2026-03-30 - Zero-allocation numeric parsing in FastParseDouble
**Learning:** C++17 `std::from_chars` natively handles parsing floats that start or end with a decimal point (like `.5` or `5.`). The previous implementation defensively created a `std::string` wrapper to manually pad these with zeroes, generating an unnecessary heap allocation on every single parse call which violated the Zero-Allocation policy and caused a bottleneck.
**Action:** When working with modern C++ numeric parsing, rely on the standard library's inherent parsing robustness instead of defensively wrapping string views into heap-allocated strings for preprocessing. Always preserve a fallback `std::strtod` path with a small stack buffer for systems lacking float support in `from_chars` (like older Apple Clang).
