## 2024-05-24 - Converting Eigen::Matrix to numpy ndarray
**Learning:** In `NanobindInterface::ConvertToNumPyMatrix`, the implementation creates a nested `std::vector<std::vector<double>>` and passes it to `np.array(nested, dtype="float64")`. This involves allocating many small vectors and converting them into a Python list of lists before numpy creates the array. Nested vector allocation is over 10x slower than a flat vector allocation (572ms vs 48ms for 100 iterations of 1000x1000 matrices in C++).
**Action:** Replace the nested vector copy with a flat array allocation and use `np.array(flat).reshape(rows, cols)` (or nanobind's built-in cast for a flat array which can then be reshaped), or pass the matrix's raw memory buffer to numpy with a reshape, ensuring row-major vs column-major conversions are correct (since Eigen defaults to column-major and Numpy to row-major).
