## 2024-10-24 - [Optimizing SQLite Iterator memory allocation]
**Learning:** In Python's `sqlite3` module, using `.fetchall()` to materialize intermediate rows into a list before iterating over them (e.g., `[r[0] for r in cursor.fetchall()]`) is a memory and performance anti-pattern. Direct cursor iteration in a comprehension (e.g., `[r[0] for r in cursor]`) avoids intermediate tuple list allocations, reducing peak memory usage and improving execution time.
**Action:** Use direct cursor iteration `[r[0] for r in cursor]` instead of `.fetchall()` in SQLite queries to optimize memory and execution time.
