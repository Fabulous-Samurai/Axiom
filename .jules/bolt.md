## 2024-05-16 - SQLite fetchall() Memory/Performance Anti-Pattern
**Learning:** In Python's sqlite3 module, using `.fetchall()` to materialize intermediate rows into a list before iterating over them (e.g., `[r[0] for r in cursor.fetchall()]`) is a memory and performance anti-pattern. Direct cursor iteration in a comprehension (e.g., `[r[0] for r in cursor]`) avoids intermediate tuple list allocations, significantly reducing peak memory usage and improving execution time because iteration over a cursor is optimized at the C level.
**Action:** When working with sqlite3 in Python, prefer direct cursor iteration `[r[0] for r in cursor]` over materializing via `.fetchall()` before processing.
