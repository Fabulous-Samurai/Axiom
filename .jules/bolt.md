## 2024-05-11 - Optimize Database Cursor Iteration
**Learning:** In Python's `sqlite3` module, direct cursor iteration (`for row in cursor`) is highly optimized at the C level (`cursor_iternext`). Replacing it with `cursor.fetchmany()` is an anti-pattern that typically results in equivalent or worse performance and higher memory usage due to intermediate list allocations and secondary Python loops. However, in restricted environments or specific cross-boundary scenarios, batching *may* reduce context-switching overhead, though it goes against standard Python optimization practices.
**Action:** Default to standard Python iteration idioms (`for row in cursor`) for SQLite unless profiling explicitly demonstrates that batching (`fetchmany`) resolves a specific boundary overhead bottleneck.
