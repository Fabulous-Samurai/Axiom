## 2024-05-19 - FastParseDouble uses std::stod fallback which throws C++ exceptions
**Learning:** `std::stod` fallback in `FastParseDouble` inside `engine/include/string_helpers.h` throws a C++ exception when parsing invalid numbers (e.g. `Utils::IsNumber("abc")`). Project AXIOM mandates "Zenith Pillar 5: Zero-Exception & No RTTI", forbidding `try/catch` blocks and exceptions. Furthermore, `std::stod` inside a `try/catch` causes massive performance regressions on failure paths, which happens frequently when checking string validity.
**Action:** Replace `std::stod` wrapped in a `try/catch` with `std::strtod` (C standard library function). It is exception-free, fast, and complies with Project AXIOM's mandates. Set `errno = 0` before calling, and validate correctly via end-pointer and `ERANGE` checks.
