## 2024-10-24 - Zero-Allocation Exception-free floating-point parsing
**Learning:** Using `std::stod` inside a `try/catch` block for fallback parsing creates severe performance regressions because `std::stod` throws C++ exceptions on invalid input. Furthermore, manually padding strings using `std::string` heap allocations violates Zenith Pillar 1 (Zero-Allocation) and causes massive CI failures. `std::from_chars` natively supports general float format without padding.
**Action:** Replace `std::stod` with the exception-free `std::strtod` and completely remove `std::string` allocations, operating purely on `std::string_view` for high-performance string-to-number parsing.
